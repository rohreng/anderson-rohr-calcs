## 4. Phase 0 — ASCE 7-16 corrections

### 4.1 Interpolation (replaces `interpGCp` / `AREAS`)
All GCp curves become breakpoint arrays `[[A_sf, GCp], …]`; piecewise **log-linear in log10(A)** between consecutive breakpoints; constant outside the first/last breakpoint; A floored at 10 sf before evaluation (D-6).
```js
function interpSeg(seg, A){
  var x=Math.log10(Math.max(A,10)), n=seg.length;
  if(x<=Math.log10(seg[0][0])) return seg[0][1];
  if(x>=Math.log10(seg[n-1][0])) return seg[n-1][1];
  for(var i=0;i<n-1;i++){ var x0=Math.log10(seg[i][0]), x1=Math.log10(seg[i+1][0]);
    if(x>=x0&&x<=x1) return seg[i][1]+(seg[i+1][1]-seg[i][1])*(x-x0)/(x1-x0); }
  return seg[n-1][1];
}
function gcpAt(arr, A){ return (arr===null||arr===undefined) ? null : interpSeg(arr, A); }
```
Delete `AREAS` and `interpGCp`; replace the calls at :1215-1216, :1333-1334, :1339, :1430-1431 with `gcpAt`. Detail Step 3 (:1644-1657) prints "piecewise log-linear between the figure breakpoints" and the breakpoint list `[10: −1.7, 500: −1.0]` instead of the FORECAST.LINEAR text and six-value arrays. Notes :385 and :1244 likewise.

The parapet Zone 2/3 worst-case merge (:1313-1330) changes from element-wise `Math.min` over six-value arrays to **min over the matching zones of `gcpAt(z.neg, A)`** evaluated at the component A (and at each reference area). §4.6 gives the resulting numbers.
